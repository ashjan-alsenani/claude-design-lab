# رحلة إلى كنوز المعرفة

مغامرة تعليمية تفاعلية لدرس «من مصادر التشريع الإسلامي (1)» (الدرس الخامس، ص 74–75 وصفحة «أفهم وأصنّف»).

**إعداد الطالبة: جنى الخاطري**
ثماني جزر عائمة، لكل جزيرة نشاط يعمل فعليًا، حتى قصر التتويج والشهادة.

## التشغيل

```bash
cd knowledge-journey
npm install
npm run dev        # للتطوير: http://localhost:5173
npm run build      # نسخة النشر في مجلد dist/
npm run preview    # معاينة نسخة النشر
```

مجلد `dist/` موقع ثابت بالكامل (HTML وCSS وJS وخطوط مضمّنة)، يعمل من أي استضافة ثابتة أو من مجلد فرعي (مثل GitHub Pages) لأنه يستخدم روابط نسبية وتوجيه `#/`. لا يحتاج خادمًا ولا قاعدة بيانات ولا أي خدمة مدفوعة.

## فيديو: كيف أستخدم الموقع؟

زر «كيف أستخدم الموقع؟» في الصفحة الأولى وفي لوحة المعلمة يفتح جولة مصوّرة (4:36 دقيقة) بشرح نصي على الشاشة: الوضع الجماعي، الفرق والدور، الأنشطة، لوحة المعلمة، والتتويج.
الملفان: `public/media/how-to-use.mp4` و`public/media/how-to-use.webm`.

الفيديو مسجَّل آليًا من الموقع الحقيقي، فيمكن إعادة تسجيله بعد أي تعديل:

```bash
npx vite --port 4173 &
node scripts/record-tutorial.mjs http://localhost:4173/ public/media/how-to-use.mp4
```

(يحتاج ffmpeg. لا يتضمن تعليقًا صوتيًا؛ الشرح نص على الشاشة.)

## جماعي أولًا، وفردي عند الحاجة

الرحلة مصمّمة أساسًا لتُعرض على السبورة. بعد «لنبدأ المغامرة» تختار المعلمة نوع الرحلة (الجماعي هو الخيار المقترح):

- **فردي:** طالبة واحدة على جهازها، تكتب اسمها، وتحصل على شهادة باسمها.
- **جماعي (للسبورة):** تختار المعلمة الفرق المشاركة (فريق النجوم، اللؤلؤ، الجواهر، القمر) واسم الصف. تظهر لوحة نقاط الفرق أعلى كل شاشة، والدور يتناوب بين الفرق على **كل سؤال في الجزر الثماني**؛ الفريق صاحب الدور يأخذ النقاط إذا أجاب صحيحًا. مع كل إجابة تعلن «سَنا» اسم الفريق ونقاطه، ويظهر إعلان كبير «الدور على فريق …». تكبر الخطوط تلقائيًا لتُقرأ من آخر الصف، وفي قصر التتويج تظهر منصة ترتيب الفرق وشهادة الفريق المتصدّر.

## الجزر الثماني

| # | الجزيرة | ما يحدث فعليًا |
|---|---|---|
| 1 | بوابة المعرفة | بوابتان تنفتحان (القرآن / السنة)، بطاقات تُكشف بالنقر، سؤال لكل بوابة، ثم تحدي «المصدر الصحيح» (6 عبارات). |
| 2 | صندوق الكنوز المفقودة | سحب وإفلات حقيقي (فأرة ولمس) لثماني بطاقات إلى ثلاثة صناديق، أو «اضغطي البطاقة ثم الصندوق». الصندوق يفتح وتخرج جوهرة عند الصواب، وتلميح عند الخطأ. |
| 3 | عجلة التحديات | العجلة تدور بفيزياء تباطؤ، ونوع التحدي يُحسب من زاوية التوقف الفعلية (6 أنواع منها «سؤال سريع» بمؤقت). 6 جولات دون تكرار الأسئلة. |
| 4 | المحققة الذكية | 6 قضايا من السهل إلى الصعب، أدلة تُكشف بالنقر، ختم «تم حل القضية»، وشرح خاص لكل خيار خاطئ. |
| 5 | أحجية المعرفة | خريطة مفاهيم السنة (7 قطع)، سحب أو نقر، زر «تحقّقي» يثبت الصحيح ويعيد الخاطئ، تلميح، وإعادة محاولة. |
| 6 | السينما التفاعلية | فيلم متحرك مبرمج مدته 86 ثانية بساعة زمنية حقيقية: تشغيل، إيقاف، تقديم، ملء الشاشة، ترجمة نصية متزامنة. يتوقف عند 3 أسئلة ولا يمكن تجاوزها بالتقديم. |
| 7 | تحدي البرق | 10 أسئلة عشوائية × 15 ثانية، مؤقت دائري حقيقي، نقاط حسب الصواب والسرعة، حالة «انتهى الوقت». ومنها **المنافسة الصفية** على جهاز المعلمة. |
| 8 | قصر التتويج | بوابة ذهبية، لوحة النتائج، اللقب، الشارات، وشهادة باسم الطالبة تُنزَّل PNG أو تُطبع. |

يُحفظ التقدم تلقائيًا في `localStorage` على جهاز الطالبة، والجزر تُفتح بالتسلسل ويمكن إعادة أي نشاط مكتمل.

## لوحة المعلمة (`#/teacher`)

- عرض بنك الأسئلة (60 سؤالًا) مع بحث وتصفية بالموضوع والنوع.
- إضافة سؤال، تعديله، حذفه، تحديد الإجابة الصحيحة، كتابة التفسير، النوع، الصعوبة، الموضوع.
- تصدير البنك JSON واستيراده، واستعادة البنك الأصلي.
- مدة مؤقت تحدي البرق وعدد أسئلته، ومؤقت «السؤال السريع» في العجلة.
- خيار «فتح جميع الجزر» للعرض على السبورة.
- المنافسة الصفية: فريق النجوم / اللؤلؤ / الجواهر / القمر، تناوب الأدوار، لوحة ترتيب كبيرة تناسب شاشة الصف، وسجل الجلسات مع تصفير أو حذف كل جلسة.
- نتائج الطالبة المحفوظة على هذا الجهاز.

**عن الحماية:** التعديلات تُحفظ على جهاز المعلمة ومتصفحها فقط. لم توضع كلمة مرور لأن أي كلمة مرور داخل كود المتصفح يمكن قراءتها ولا تحمي شيئًا. إذا احتجتِ حفظًا مشتركًا بين أجهزة، أو منافسة مباشرة على أجهزة الطالبات، فذلك يتطلب خادمًا بمصادقة وصلاحيات حقيقية وقاعدة بيانات بتحديث لحظي — وهو غير مُفعّل هنا.

## تعديل المحتوى مستقبلًا

| ما تريدين تعديله | الملف |
|---|---|
| بنك الأسئلة (يمكن أيضًا من لوحة المعلمة) | `src/data/questions.json` |
| محتوى البوابتين، البطاقات، القضايا، قطع الأحجية | `src/data/lesson.ts` |
| نص الفيلم، توقيت الترجمة، أسئلة التوقف | `src/data/film.ts` |
| الآيات (بالرسم العثماني) | `src/data/verses.ts` |
| أسماء الجزر وعناوينها | `src/data/activities.ts` |

لكل سؤال: `id`، `type` (`mcq` · `truefalse` · `complete` · `definition` · `sunnahType`)، `text`، `options`، `answer` (رقم الخيار الصحيح بدءًا من 0)، `explanation`، `difficulty` (`easy` · `medium` · `hard`)، `topic`.
لإدراج آية في أي نص اكتبي رمزها بين قوسين مزدوجين، مثل `[[hijr9]]`، فتُعرض بالرسم العثماني مع اسم السورة ورقم الآية.
تحدي البرق يأخذ الأسئلة ذات الخيارات الأربعة فقط، ويُعاد ترتيب الخيارات عشوائيًا عند العرض (عدا صح/خطأ ونوع السنة).

بعد تعديل الملفات شغّلي `npm test` للتأكد من سلامة البنك (المعرّفات، الإجابات، رموز الآيات…).

## الدقة العلمية

- كل سؤال وشرح مستمد من صفحات الكتاب المرفقة فقط، ولم تُضف أحاديث غير الواردة فيها: «المسلم أخو المسلم» (البخاري 2442) والنهي عن كل ذي ناب ومخلب (مسند الربيع 387) كما نسبهما الكتاب.
- نصوص الآيات بالرسم العثماني من مصحف Tanzil (عبر api.alquran.cloud)، وقُصّت المقاطع آليًا كلمةً كلمة من نص الآية الكامل دون إعادة كتابتها يدويًا، وتُعرض بخط Amiri Quran.
- لا يُجسَّد النبي ﷺ ولا الصحابة؛ الفيلم يستخدم كتابًا ولفافة وفوانيس ورموزًا فقط.

## الصوت والفيديو

- كل المؤثرات الصوتية والموسيقى الهادئة مولّدة برمجيًا (Web Audio) — أصلية بالكامل، بلا ملفات أو تراخيص. الموسيقى لا تبدأ إلا بضغط زر الموسيقى، ويوجد زر لكتم المؤثرات.
- **التعليق الصوتي للفيلم يحتاج ملفًا خارجيًا:** لم يُستخدم صوت آلي لأن الأصوات المجانية رديئة في العربية. الفيلم يعمل الآن بترجمة نصية متزامنة. لإضافة صوت: سجّلي التعليق (86 ثانية تقريبًا) بنفس نصوص `CAPTIONS` وتوقيتاتها في `src/data/film.ts`، ضعيه في `public/media/narration.mp3`، ثم غيّري `NARRATION_SRC` إلى `'media/narration.mp3'`. المشغّل يزامنه تلقائيًا مع التشغيل والإيقاف والتقديم ونقاط الأسئلة.

## التقنيات

React 19 + TypeScript + Vite، Framer Motion للحركة، SVG وCSS 3D للرسوم (كلها مرسومة خصيصًا للمشروع)، Canvas للشهادة، خطوط El Messiri وReadex Pro وAmiri Quran مضمّنة محليًا. يحترم إعداد «تقليل الحركة» في النظام. لم يُستخدم Three.js لأن المشاهد تتحقق بـ SVG/CSS بحمل أخف على أجهزة الطالبات.
