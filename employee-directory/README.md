# دليل موظفي الرقمية والتقنية (نسخة تجريبية محلية)

موقع ثابت (HTML وCSS وJavaScript) لدليل موظفين ببيانات وهمية بالكامل. لا يحتاج خادمًا خلفيًا: طبقة `/api` محاكاة داخل المتصفح، والتعديلات تُحفظ في `localStorage` على جهازك فقط.

**غير منشور:** لا يوجد أي إعداد نشر (GitHub Pages أو Vercel أو غيرها)، وصفحة الموقع تحمل `noindex, nofollow`.

## التشغيل محليًا

```bash
cd employee-directory
python3 -m http.server 8000 --bind 127.0.0.1
```

ثم افتحي <http://127.0.0.1:8000>. يمكن أيضًا فتح `index.html` مباشرة في المتصفح.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `assets/app.js` | التطبيق والبيانات التجريبية (حزمة مبنية مسبقًا) |
| `assets/styles.css` | التنسيقات |
| `assets/fonts/` | خط IBM Plex Sans Arabic (رخصة SIL OFL)، أوزان 400–700 |

## ملاحظات

- **حفظ التقدم:** كل تغيير يُحفظ تلقائيًا في المتصفح (مؤشر «كل شيء محفوظ» أعلى الصفحة). أثناء تعديل بيانات موظف تُحفظ مسودة، وإذا أُغلقت الصفحة قبل الحفظ يظهر خيار «استرجاع» عند العودة.
- **النسخ الاحتياطي:** من زر «بيانات تجريبية» يمكن تنزيل نسخة احتياطية (ملف JSON) واسترجاعها لاحقًا أو على جهاز آخر. إعادة البيانات التجريبية تطلب تأكيدًا.
- **الصلاحيات:** حساب Ashjan Al Sinani هو المسؤول الوحيد؛ أزيل مبدّل «العرض بصفة».
- **أبرز الكفاءات:** صفحة ترتّب الموظفين بدرجة من 100 حسب الجاهزية وأهمية المهارة والموظف والشهادات والدورات (طريقة الحساب موضحة في الصفحة).
- **الهيكل التنظيمي:** صفحة بمستويات VP ← GM ← SM ← M ← TL ووحداتها، مع موظفي كل وحدة. أصبحت هذه الوحدات خيارات حقل «الإدارة / القسم»، ونُقل الموظفون التجريبيون إلى أقرب وحدة مطابقة.

- **الحقول المخصصة:** من «إدارة بيانات الموظفين ← الحقول المخصصة» يستطيع المسؤول إضافة حقول جديدة (نص قصير، نص طويل، رقم، تاريخ، نعم/لا، اختيار من قائمة)، وتعديلها وترتيبها وحذفها. ويمكن أيضًا إضافة حقل مباشرة من نموذج الموظف بزر «إضافة حقل جديد هنا» أسفل كل قسم، دون فقدان ما كُتب في النموذج. تظهر مباشرة في نموذج الموظف وفي تبويب «البيانات الشخصية والوظيفية» داخل قسم «معلومات إضافية».

- الدخول كمسؤول باسم المستخدم `Ashjan Al Sinani` (لا يهم حجم الأحرف) وكلمة المرور التي اتفقنا عليها. كلمة المرور غير مكتوبة في الكود؛ يُحفظ تجزئتها (SHA-256) فقط.
- التحقق يتم داخل المتصفح فقط؛ هذا مناسب للعرض التجريبي وليس حماية حقيقية.
- جميع الأسماء والبريد (`example.com`) وأرقام الهواتف وهمية.
