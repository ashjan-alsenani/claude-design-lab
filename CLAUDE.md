# Design lab

This is an independent experimental project. Work only inside this repository.
Use fictional/sample data. Do not read or modify sibling projects, workplace documents, secrets, or account credentials.
Do not install skills globally, add automatic hooks, deploy, or change GitHub visibility without an explicit user request.
Keep normal tool permission prompts enabled. These instructions are scope guidance, not a security sandbox.

## Design skills
- Use `design-taste-frontend` for landing-page and portfolio direction.
- Use `emil-design-eng` for interface details and motion.
- Use `impeccable` for layout, typography, audits and final polish.
- Follow the user's brief over conflicting aesthetic defaults. Prefer comfortable spacing, readable typography and restrained motion unless asked otherwise. Support Arabic RTL when requested.

Impeccable includes upstream executable launchers. Its first invocation may download and execute a versioned engine outside this repository in the user's cache. Explain that action before requesting normal tool permission. Do not bypass a refusal: use the skill's documented launcher-unavailable fallback instead. Hooks have not been installed here.
