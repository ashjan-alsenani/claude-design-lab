# Claude Design Lab

مساحة مستقلة لتجربة تصميم المواقع باستخدام ثلاث مهارات لـ Claude Code.

## المهارات الموجودة

| المهارة | الاستخدام | الأمر |
|---|---|---|
| Emil Design Engineering | تفاصيل الواجهة والحركة | `/emil-design-eng` |
| Impeccable | المسافات والخطوط والمراجعة والصقل | `/impeccable polish` |
| Taste | اتجاه تصميم صفحات الهبوط والبورتفوليو | `/design-taste-frontend` |

توجد المهارات مع ملفاتها المساندة داخل `.claude/skills/`. هذه نسخ من المهارات الأساسية الثلاث، وليست جميع المهارات الاختيارية في المستودعات الأصلية.

## الاستخدام على الكمبيوتر

بعد تثبيت Git وClaude Code، افتحي Terminal في مكان مخصص للتجارب ثم نفذي:

```bash
git clone https://github.com/ashjan-alsenani/claude-design-lab.git
cd claude-design-lab
claude
```

لا تحتاجين تشغيل أوامر npx لتثبيت هذه النسخ؛ الملفات موجودة بالفعل. إذا كان المستودع خاصًا ستحتاجين تسجيل الدخول إلى GitHub للوصول إليه.

داخل محادثة Claude Code، ابدئي بـ:

```text
/impeccable init
```

ثم اشرحي الموقع الذي تريدينه. مثال:

> أنشئ صفحة هبوط تجريبية عربية وإنجليزية مريحة للعين. استخدم بيانات وهمية، مسافات واسعة، خطوطًا واضحة وحركات خفيفة، مع دعم الهاتف واتجاه العربية. استفد من Taste للتوجه البصري وEmil لتفاصيل الحركة، ثم Impeccable للصقل.

بعد بناء الصفحة:

```text
/impeccable polish
```

يمكن كتابة `/` لرؤية الأوامر المتاحة. حفظ هذه الملفات على GitHub وحده لا يثبتها في محادثة Claude العادية؛ يجب فتح هذا المشروع في Claude Code.

## حدود الإعداد

- النسخ محلية لهذا المشروع؛ لم نثبت شيئًا على جهازك أو داخل حساب Claude.
- لم نضف GitHub Actions أو hooks تلقائية أو موافقات شاملة للأوامر.
- المستودع المنفصل ليس sandbox أمنيًا. احتفظي بطلبات الموافقة المعتادة واستخدمي بيانات تجريبية فقط.
- Impeccable يتضمن مشغلات من المصدر الأصلي؛ عند أول استخدام قد ينزل ويشغل محركًا تنفيذيًا في cache المستخدم خارج مجلد المشروع. يمكن رفض تشغيله واتباع البديل النصي الموثق في المهارة.
- لم يُنفذ المحرك أو تُجرّب جلسة Claude Code هنا؛ فُحصت بنية الملفات وتطابقها مع المصادر. هذا ليس تدقيقًا أمنيًا شاملًا.
- كان المستودع Public عند الإعداد. لا ترفعي معلومات سرية.
