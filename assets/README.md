# Logo files

The logos supplied by the project owner, prepared for the web and embedded into `index.html` by `build.py`:

- `omantel-logo.webp`: Omantel logo (from `src/omantel-original.webp`).
- `clickup-logo.webp`: ClickUp wordmark, trimmed of empty margin, transparent background (from `src/clickup-wordmark-original.jpg`).
- `clickup-icon.webp`: ClickUp icon, used as the browser tab icon (from `src/clickup-icon-original.png`).

`src/` keeps the original files unchanged, including `pso-hub-original.png` (not used yet). The logos are shown in their original colours and proportions: never redrawn, recoloured or stretched. Each logo is embedded once; the language screen and footer reuse the header copy at start-up.
