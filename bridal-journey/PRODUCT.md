# Bridal Journey product scope

The product is a personalized bridal planning web application for GCC brides.

## Primary dashboard questions
The home screen must answer:
1. How many days remain?
2. How ready am I?
3. What should I focus on this week?
4. What appointment is next?
5. What payment is coming?
6. What have I forgotten?

## Main modules
- Dashboard
- Smart bridal checklist
- Calendar / appointments
- Budget and payments
- Vendors
- Guests and RSVP
- Bridal preparation
- Bridal closet / shopping
- Events: engagement, عقد/ملكة, henna, bridal shower, wedding, صباحية
- New home setup
- Honeymoon
- Wedding-day timeline
- SOS kit
- Inspiration / moodboard
- Documents

## Personalization
Onboarding should collect wedding date, city/country, budget/currency, guest count, enabled events, home setup, honeymoon and planning status.

Tasks should calculate relative to the wedding date and appear as Today / This Week / Coming Soon / Later rather than dumping the full list.

## GCC fit
Support OMR, AED, SAR, QAR, KWD, BHD and USD.
Allow users to disable traditions/events that do not apply.
Arabic must be a first-class experience.

## Data
The final commercial product should persist authenticated user data securely. The current static prototype is visual scaffolding, not the final backend architecture.
