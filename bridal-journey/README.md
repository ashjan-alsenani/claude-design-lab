# رحلة العروس · Bridal Journey

A dedicated visual foundation for the premium Arabic-first bridal planner.

## Start here
Open `bridal-journey/index.html` in a browser. It is the working dashboard prototype.

The target reference is stored at:
`assets/reference-tiny.jpg`

## Goal
The final application should feel like a premium GCC bridal assistant rather than a checklist document. It should guide a bride through tasks, appointments, budget, vendors, guests, shopping, home setup, honeymoon and wedding-day preparation.

## Current visual foundation
The prototype already includes:
- luxury ivory / champagne / blush visual system
- Arabic RTL dashboard
- real bride hero image crop
- wedding countdown and progress ring
- five summary cards
- weekly focus checklist
- upcoming appointments with image thumbnails
- budget overview
- phone task preview
- phone budget preview
- responsive layouts
- functional task toggles and tabs
- dedicated SVG bridal icons

## Important files
- `index.html` — visual dashboard prototype
- `CLAUDE.md` — implementation rules for Claude
- `DESIGN.md` — design tokens and geometry
- `PRODUCT.md` — product scope
- `ASSET_MANIFEST.md` — exact asset paths and intended usage
- `assets/reference-tiny.jpg` — visual reference

## Claude Code
From the repository root, work only in this folder for the bridal product. Run the existing design skills when useful, then polish against the supplied reference.
